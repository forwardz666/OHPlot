# 工具栏悬停提示（Tooltip）规范

> 2026-07-29 新增。对齐桌面版 SciDAVis 的行为：鼠标悬停到工具栏按钮上时，
> 弹出该功能的名称气泡，**即使该功能尚未适配**也照常显示，以提升用户的功能
> 发现能力。

## 一、目标与适用范围

- 顶部工具栏（`ToolBar.ets`）与底部工具栏（`BottomToolBar.ets`）的**每个按钮**
  （含普通按钮 `ToolButton` 与下拉按钮 `DropButton`）都必须携带悬停提示；
- 提示文本随系统语言切换（中/英），走多语言资源（详见规范 07）；
- 提示为悬停交互效果，仅鼠标 / 触控板的 hover 触发，触摸点击不触发。

## 二、API 选型与兼容性约束

| 方案 | 触发 | 要求 | 结论 |
|---|---|---|---|
| `bindTips(TipsMessageType)` | 原生 hover 气泡 | **API 19+** | 项目 `compatibleSdkVersion` 为 API 17，编译期 API 门禁会失败，**不可用** |
| `onHover` + `bindPopup` | 自管 hover 状态 | **API 8+** | 无需改 build config / SDK，**采用** |

> 设备运行时为 API 26（支持 bindTips），但编译期受 `compatibleSdkVersion 17`
> 限制，故不能用 bindTips。若后续提升 compatibleSdkVersion 至 19+，可迁移到
> bindTips 简化实现。

## 三、实现模式（onHover + bindPopup）

### 3.1 状态与本地化助手

```typescript
// 当前被鼠标悬停的按钮 id，驱动 tooltip 弹出（空 = 无 tooltip）
@State hoverTipId: string = '';

// bindPopup.message 是 string 而非 ResourceStr，需经资源管理器同步解析
private tipText(name: string): string {
  try {
    return getContext(this).resourceManager.getStringByNameSync(name);
  } catch (e) {
    return '';
  }
}
```

### 3.2 按钮绑定（@Builder 内）

```typescript
.onHover((isHover: boolean) => {
  if (isHover) {
    this.hoverTipId = $$.id;
  } else if (this.hoverTipId === $$.id) {
    this.hoverTipId = '';
  }
})
.bindPopup(this.hoverTipId === $$.id, {
  message: this.tipText($$.tip),
  placement: Placement.Bottom,   // 顶部工具栏向下弹；底部工具栏用 Placement.Top
  enableArrow: true,
  autoCancel: false,
  popupColor: '#FFFFE1',
  onStateChange: (e) => {         // 无需类型标注，ArkTS 上下文类型推断
    if (!e.isVisible && this.hoverTipId === $$.id) {
      this.hoverTipId = '';
    }
  }
})
```

## 四、规范要点

1. **按钮契约扩展**：`TbButtonOpts` / `TbDropOpts` 接口新增 `tip: string` 字段，
   值为提示文本的**资源名**（如 `'tip_open'`），不是字面文本。
2. **placement 依位置**：顶部工具栏用 `Placement.Bottom`（向下弹），底部工具栏用
   `Placement.Top`（向上弹），避免气泡越出屏幕边界。
3. **响应性**：`hoverTipId` 用 `@State`，`onHover` 更新它触发 `build()` 重跑，
   使 `bindPopup` 的显隐条件 `this.hoverTipId === $$.id` 生效；`@Builder` 参数
   仍按单对象字面量传引用（见规范 01 的 @Builder 响应性约定）。
4. **未适配也显示**：tip 与按钮是否已适配无关，所有按钮都配 tip 资源名，
   契合“功能发现”目标。
5. **资源对齐**：每个 `tip_*` 键必须在 base / en_US / zh_CN 三份 string.json
   同步新增（详见规范 07）。
6. **验证**：静态截图无法展示 hover 效果，需在真机用**鼠标**悬停确认；断言可用
   `uitest dumpLayout` 查 popup 节点存在性。
