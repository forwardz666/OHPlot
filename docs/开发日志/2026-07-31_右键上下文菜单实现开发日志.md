# 2026-07-31 工作日志：右键上下文菜单实现

- 菜单项根据当前活动窗口类型（Table/Graph/Matrix）动态切换

## 完成项
- [x] 创建 `components/ContextMenu.ets`：浮动上下文菜单组件，支持按 activeType 动态生成菜单项
- [x] 修改 `pages/MainLayout.ets`：导入 ContextMenu，添加状态变量，在 onMouse 中检测右键点击，在 Stack 中添加 ContextMenu 覆盖层
- [x] 右键事件同时转发到 Qt（sendMouse），保持后端处理不受影响
- [x] 半透明遮罩层（scrim）实现点击菜单外部区域关闭菜单

## 技术决策
- **决策 1**: 上下文菜单使用完全独立的 `ContextMenu` 组件（而非复用 `DropdownMenu`），因为它的定位方式不同（固定在右键坐标而非菜单栏下方），且菜单项可直接配置而无需走 MenuItemData 模型
- **决策 2**: 右键检测在 onMouse 中 `openMenu` 守卫之前执行，确保即使用户已打开菜单栏下拉菜单，右键仍能显示上下文菜单（桌面行为对等）
- **决策 3**: 菜单项 ID 复用现有 `onMenuItemClick` 分发系统 — `cut/copy/paste/delete` 走 fallback → menuAction，`graph_props/export_image/set_dimensions/set_values/transpose/invert` 走专用 case，`add_curve/add_error_bars/add_function/insert_row/insert_col/clear_selection` 走默认 → menuAction → not-adapted 提示

## 遗留问题
- `insert_row`、`insert_col`、`clear_selection` 等菜单项在现有 dispatchMenuItem 中无专用 case，走 fallback → menuAction → Qt 返回 unsupported → 显示"未适配"提示
- 触控设备长按映射右键尚未实现（当前仅蓝牙鼠标右键支持）
- 菜单定位未处理边界溢出（右下角附近右键时菜单可能超出屏幕）
