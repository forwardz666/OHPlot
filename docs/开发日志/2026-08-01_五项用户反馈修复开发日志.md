   - 问题1：侧边栏只在 `currentView==='tables'` 挂载，默认视图（Qt 原生穿透）下不渲染；且 `selectedCol` 初始 -1 门控 description 区。
   - 问题3：Qt 侧 `setContentsMargins` 依赖 resize 事件时序，启动竞态下 MDI 子窗口停在 (0,0) 被覆盖层遮挡。
   - 问题4：内容区右键 = ArkTS ContextMenu（非 bug）；工具栏右键失灵 = `bindPopup` 默认 `mask:true` 模态遮罩吞掉右键。
   - 问题5：无 restore 状态机，`setMaximized()` 对已最大化窗口 no-op；uiState 已带 status 但未消费；按钮刷新时序早于 Qt 排队命令。
2. **并行修复**（3 agent）：

   - Agent B（Qt）：`setContentsMargins` → `setViewportMargins`（qobject_cast + ViewportMarginAccessor 访问 protected 成员）；新增 `restore_window` 命令 + `ApplicationWindow::restoreWindow()`。
   - Agent C（ToolBar）：两处 `bindPopup` 加 `mask: false`。
3. **代码审查**（1 agent）：无阻塞项；2 个重要项——①激活 Graph 时 'tables' 覆盖层不撤遮住图形；②View→Tables 关闭开关被 refreshUiState 弹回。

## 技术决策

- **决策 1（问题1）**: 表格激活自动切 tables 视图（非手动覆盖），使侧边栏进入用户默认路径；用户显式切换后 `userViewLocked=true` 让位。
- **决策 2（问题3）**: 用 `setViewportMargins` 替代 `setContentsMargins`——前者立即无条件触发 layoutChildren，无可见性/resize 事件时序依赖；访问 protected 成员用标准 `using` 惯用法（ViewportMarginAccessor）。
- **决策 3（问题4）**: `mask:false` 使悬停气泡不再模态拦截事件（视觉不变）；`autoCancel:false` 保持气泡常显。
- **决策 4（问题5）**: 新增 `restore_window` 命令 + `ApplicationWindow::restoreWindow()`（updateWindowLists+setNormal+emit modified，与 maximize/minimize 对称）；ArkTS 侧按 `uiState.windows[].status===2` 驱动 ❐/□ 切换。
