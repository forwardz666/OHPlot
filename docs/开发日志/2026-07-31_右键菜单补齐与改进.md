## 工作内容

### 子任务 1：触摸长按→右键映射
- **MainLayout.ets**: 扩展 onTouch handler，在 TouchType.Down 时记录触摸坐标和时间，TouchType.Up 时检测是否满足长按条件（≥500ms 且移动 ≤20vp）
- 检测到长按时设置 `contextMenuX/Y` 和 `showContextMenu = true`，触发 ContextMenu 显示
- 不影响现有蓝牙鼠标右键（onMouse handler 保持不变）

### 子任务 2：菜单边界溢出检测
- **ContextMenu.ets**: 新增 `getAdjustedPosition()` 方法，计算屏幕边界
- 使用 `display.getDefaultDisplaySync()` 获取运行时屏幕宽高
- 动态计算菜单高度（菜单项 28px + 分隔线 5px + 内边距 10px）
- 右边界溢出时自动左移，下边界溢出时自动上移

### 子任务 3：菜单项对接 Qt 后端
- **MainLayout.ets**: 将 `insert_row`、`insert_col`、`clear_selection` 加入 `MENU_ACTION_SUPPORTED` 白名单
- **scidavis/scidavis/src/main.cpp**: 新增 `#include "Table.h"`，扩展 `menuAction` 命令分发器
  - `clear_selection` → `g_mainWindow->clearSelection()`
  - `insert_row` → `activeWindow()` → `static_cast<Table*>(w)->insertRow()`
  - `insert_col` → `static_cast<Table*>(w)->insertCol()`

---

## 技术决策

- **长按阈值 500ms / 20vp**: 与 Android 系统长按标准一致（500ms ~ 1s），20vp 移动容差防止滑动误触
- **@ohos.display 获取屏幕尺寸**: 运行时动态获取，适配不同分辨率设备
- **insert_row/insert_col 走 Qt 后端**: 复用 SciDAVis 桌面版的 `Table::insertRow()`/`insertCol()` 方法，避免重复实现
- **clear_selection 复用 delete**: 与桌面版 `ApplicationWindow::clearSelection()` 行为一致，同一方法
