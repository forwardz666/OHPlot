## 技术决策

- **决策 1（结构化图标槽）**: ArkUI 空组件占位符（Blank/空 Row/空 Text）在含 layoutWeight 的 Row 中折叠为 0 宽，必须用含真实子内容（隐藏 Text 或 Image）的固定宽 wrapper Row 才能可靠占位。这是本轮的坑与解法：`Row(){ if(icon) Image(16×16) else Text('·').width(16).height(16).fontSize(1).fontColor(Transparent).visibility(Hidden) }.width(24).height(16).justifyContent(Start).alignItems(Center).margin({right:8})`。
- **决策 2（CJK 宽度）**: MeasureText 对中文字符低报，按每 CJK 字符 +2.5vp 膨胀 + 8vp 安全缓冲；固定 fontFamily 'HarmonyOS Sans'、px→vp 用 densityPixels 换算，中英文分别适配（用户要求可分别为两种语言设置不同长度）。
- **决策 3（图标权威清单）**: 以 Win 截图视觉逐项核对为准，删除"Win 无图标"项的 icon 字段。确认 Win 无图标项：File 的 new(级联头)/recent_projects/save_as/save_as_template/print_all_plots；Edit 的 paste/clear_log_info/preferences；Plot 的 line/scatter/line_symbol/special/statistical/panel/3d；Table 的 set_columns_as/fill_selection/hide_controls/formula_edit_mode；Analysis 大部分；Matrix 的 hide_controls/set_coordinates/transpose/mirror_h/mirror_v/invert/determinant；Windows 的 cascade/tile/rename；Help 的 choose_help_folder。仅 fit_wizard 两处补 mn_wizard（Win 有向导图标）。
- **决策 4（审查发现）**: 审查确认 4/4 需求 PASS、2 MINOR（shortcut 缺 textOverflow、ChildRow margin 16 vs SHORTCUT_GAP 20）→ quick 修复。
- **决策 5（真机验证方法）**: 截图像素级扫描 + 视觉 agent 精确测量结合；截图字节哈希对比用于判断修复是否生效（修复前 352D20F5 → 修复后 33C58197）。
