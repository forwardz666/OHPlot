  规格书 §1.1 已按此修正；OH rebuildMenus() 无需改结构。
- **决策 2（Tools 菜单）**: `plotDataMenu` 变量名 ≠ 菜单名，标题 "&Tools"；MultiLayer 激活态才出现。
- **决策 3（模型绑定）**: 用户 agent model 配置被插件 fallbackChain 覆盖时，需在**所有配置源**
  （omo.jsonc + deveco.json + deveco.jsonc + opencode.json）同时绑定，并 `fallback_models: []` 切断回退链。
