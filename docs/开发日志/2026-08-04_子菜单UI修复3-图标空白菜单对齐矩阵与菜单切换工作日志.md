## 技术决策

- **决策 1（委派分工纠偏）**: 非多模态 deep agent 用 look_at 读图低效且不可靠（初版被取消），改为"视觉 subagent 出文本清单 → deep agent 只按清单改代码"，问题 2（菜单对齐 Win）用此方式落地。
- **决策 2（@StorageProp @Watch 限制）**: ArkUI @StorageProp 的 @Watch 不响应其他组件 AppStorage.setOrCreate 的外部变更（真机验证），跨组件通知改用直接父子回调（QtEventHost 传 onWindowActivated prop 给 MainLayout）。
- **决策 3（getUiState 时序）**: getUiState 同步查询在 Qt 线程忙（窗口创建）时 3s 超时，onActiveWindowChanged 延迟 250ms + refreshUiState 有界重试（max 2，400ms 间隔）保证菜单最终重建。
- **决策 4（MouseMove 双送达）**: 手指拖动时 QPA 原生 + ArkTS sendMouse 双送达，InputProbe 原仅去重 Press/Release；新增 Move 去重（60ms + manhattan<5 + 跨 source 丢弃）减半拖动事件流量；ArkTS 侧不再转发 Move（仅 Down/Up）。
- **决策 5（矩阵）**: 删除 ArkTS MatrixPage 自动挂载，矩阵完全由 Qt 渲染（符合 2026-08-01 表格 overlay 同款决策）。
