## 技术决策

- **决策 1（子菜单定位）**: Stack(alignContent TopStart) + 子面板 .position()，父行 Y 用 computeParentRowYVp 确定性累加（28/分隔 5），避免 onAreaChange 异步竞态。
- **决策 2（宽度测量）**: MeasureText.measureText 返回 px，除以 display densityPixels 得 vp；图标槽 24vp（16 图标 + 8 间距）仅当菜单含图标项时计入；computePanelWidthVp 按最长文本（label + shortcut + 图标槽 + padding）自适应。
- **决策 3（paste 安全组件）**: PasteButton 不能自定义文字（安全控件规范），采用仅图标（PasteIconStyle.LINES）+ 旁侧自定义 Text 显示本地化文案（粘贴选中内容），保留 READ_PASTEBOARD 安全授权。
- **决策 4（延迟关闭）**: 80ms setTimeout + childPanelHovered 状态桥接父行→子面板指针过渡，防级联闪烁。
- **决策 5（语言验证）**: ArkTS 菜单语言跟随 i18n.System app preferred language（PreferencesDialog 持久化），与 Qt 侧 scidavis.ini 相互独立；本次 hdc shell -b 以应用 bundle 权限改写 scidavis.ini 为 zh-Hans 完成验证。
