## 工作内容

1. **根因调研**：
   - 表格侧边栏缺失：`TableView.cpp:131-136` OHOS 适配块 `d_control_tabs->hide()` + `d_hide_button->hide()`
     隐藏了 Qt 原生列控制面板（表格窗口的一部分）；对照 `MatrixView.cpp:119` 矩阵未隐藏 → 表格"不完整"根因。
   - 图形先全屏再缩小：`initMultilayerPlot`（2345）用 `g->show()` 首次显示（可能满幅），随后
     main.cpp new_graph 分支 showNormal → 视觉闪动。
2. **撤销 ArkTS 侧边栏**（用户明确不需要）：MainLayout.ets（import/常量/状态/方法/菜单/dispatch/浮层/守卫）、
   QtEventHost.ets（columnSelected case）、string.json×3（view_column_sidebar 键）、TableView.cpp（事件桥 +
   ohos_bridge include）、main.cpp（currentCol + setChromeInsets right）、CMakeLists（include dir）。
3. **恢复 Qt 原生表格侧边栏**：删除 TableView.cpp:131-136 OHOS 隐藏块，d_control_tabs 默认可见（与矩阵一致）。
4. **修复图形窗口状态**：`initMultilayerPlot` 的 `g->show()` → `g->showNormal()`，新图形首次显示即
   normal 无全屏闪动；main.cpp new_graph 分支保留 showNormal+setFocus 兜底。
5. **构建部署**：libentry.so 重建（TableView/ApplicationWindow 重编）→ HAP → 真机部署启动正常。

- **决策 1（侧边栏形态）**: 恢复 Qt 原生 `d_control_tabs` 列控制面板（表格窗口内嵌，Qt 渲染，
  与矩阵一致），彻底放弃 ArkTS 侧边栏方案。根因是 OHOS 适配时的隐藏块，删除即恢复。

  两调用等效，消除"先全屏再缩小"闪动，不影响桌面端与其他调用方。
- **决策 3（保留项）**: `if(OHOS)` 宏块（Q_OS_OHOS/SCIDAVIS_OHOS）保留（其他 OHOS 代码仍使用）；
  ColumnSidebar.ets 组件保留未动（TablePage 覆盖层仍引用，但仅 View→Tables 显式进入时挂载）。
