   **修复**：PIL 裁剪透明边距 + 放大到 22x22 填满（内容填满 0,0-22,22）。

## 技术决策

- **决策 1（图标格式）**: 工具栏图标统一用 **png**（避免 svg 在 ArkUI Image 的固有尺寸渲染差异）。
- **决策 2（尺寸归一）**: 图标源大于 22x22 时（如 erase 29x28），先**裁剪透明边距再缩放到 22x22**
  填满——保证内容视觉大小与其他图标一致（避免"大源图缩小、小源图放大"造成的视觉差异）。
