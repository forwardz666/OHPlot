# 2026-07-31 工作日志：长按触发右键上下文菜单

## 工作内容
在 MainLayout.ets 的 outer Stack .onTouch 处理中添加长按检测逻辑，使手指长按内容区域（500ms，位移不超过 20vp）触发 ArkTS 右键上下文菜单，等效于蓝牙鼠标右键点击。

## 完成项
- [x] 添加 5 个私有成员变量：lastTouchX/lastTouchY、touchStartTime、LONG_PRESS_DURATION_MS(500)、LONG_PRESS_MAX_MOVE_VP(20)
- [x] 扩展原有 .onTouch handler 的 TouchType.Down 分支：触屏按下时记录坐标和时间
- [x] 扩展原有 .onTouch handler 的 TouchType.Up 分支：释放时判断长按条件（时间 >= 500ms 且 平方位移 <= 20²），命中则设置 showContextMenu=true + 坐标
- [x] 添加 hilog.info 日志用于调试
- [x] ArkTS 语法检查通过，无错误

## 技术决策
- **使用平方距离判断位移**（dx*dx + dy*dy <= threshold²），避免 Math.sqrt 开销
- **复用已有 .onTouch handler**：在原有 Down 分支末尾追加记录、在 Up 分支中追加判断，不破坏现有的 sendMouse 转发逻辑
- **不转发长按事件给 Qt**：长按是纯 ArkTS 层手势，直接设置已有 @State 变量触发 ContextMenu
- **不干扰 onMouse 处理**：已有的蓝牙右键 .onMouse handler 完全不受影响
- **使用 Date.now()**：ArkTS/JS 原生可用，无需额外导入

## 代码结构

Down 分支（修改后）：
```typescript
if (t.y < this.topChromeVp() || t.y > stackHeight - STATUSBAR_HEIGHT_VP) {
  continue;
}
this.lastTouchX = t.x;
this.lastTouchY = t.y;
this.touchStartTime = Date.now();
action = 0; leftDown = true;
```

Up 分支（修改后）：
```typescript
if (!leftDown) { continue; }
const elapsed = Date.now() - this.touchStartTime;
const dx = t.x - this.lastTouchX;
const dy = t.y - this.lastTouchY;
if (elapsed >= this.LONG_PRESS_DURATION_MS &&
    (dx * dx + dy * dy) <= this.LONG_PRESS_MAX_MOVE_VP * this.LONG_PRESS_MAX_MOVE_VP) {
  this.contextMenuX = this.lastTouchX;
  this.contextMenuY = this.lastTouchY;
  this.showContextMenu = true;
}
action = 1; leftDown = false;
```
