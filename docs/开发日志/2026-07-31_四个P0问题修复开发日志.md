## 二、技术决策

### P0-1: 右键菜单
- **方案**：ArkTS 实现 `ContextMenu` 组件，全屏 scrim + 浮动面板
- **菜单项**：Table → Cut/Copy/Paste/Delete + Insert Row/Col + Clear Selection；MultiLayer → Plot Properties/Add Curve/Export Image；Matrix → Set Dimensions/Values/Transpose/Invert
- **视觉**：完全匹配 `DropdownMenu`（200px 宽、白色背景、`#CCCCCC` 边框、6px 阴影、28px 行高、14px 字体）
- **事件共存**：右键检测在 `openMenu` 守卫之前执行，上下文菜单和菜单栏下拉互不干扰；右键事件仍转发 Qt

### P0-2: Qt 菜单栏隐藏
- 在 `main.cpp` 的 `main()` 函数中，`QToolBar` 隐藏块之后添加 `menuBar()->hide()`
- 需 `#include <QMenuBar>` 完整类型定义（`qmainwindow.h` 仅前向声明）

### P0-3: 表格侧边栏
- **C++ 后端**：新增 `getColumnInfo` 命令，返回 `[{col, name, type, description, formula, plotDesignation}]` JSON 数组
- **ArkTS 前端**：`ColumnSidebar` 组件，包含列名列表（高亮选中列）+ 详情面板（6 个字段）
- **数据流**：`DataTable(@Link selectedCol)` → `TablePage(@State)` → `ColumnSidebar(@Link)`
- **UI 风格**：对齐 `MatrixOpsDialog.ets`（fontSize 13、`#555555` 标签色、`#333333` 值色、260px 宽）

### P0-4: 底部工具栏
- 移除 `if (this.uiState.activeType === 'Table')` 条件，`BottomToolBar` 始终渲染
