## 技术决策

- **决策 1（git 机械操作不委派）**: git 提交拆分/add/commit/push 前检查属编排职责，由 L1 直接执行；
  确需委派仅限 `quick` + 文件级分组映射，禁止 `deep`/研究类 category 与 hunk 级交互拆分。
- **决策 2（分叉先对比后合并）**: push 前 `git fetch` + `rev-list --left-right --count` 预检；
  分叉时先用 `diff --name-status` 判定子集/超集关系，子集场景直接 merge（ort 零冲突），
  不 rebase 不 force push。
- **决策 3（敏感词命中需上下文解读）**: 全量扫描命令覆盖 `.p12`/`BEGIN.*PRIVATE`，命中项须逐条
  核对文件与行号，文档正文引用不算真实泄密（08-02 实例 3 处命中均为引用）。
