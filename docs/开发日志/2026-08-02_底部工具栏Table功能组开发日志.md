## 技术决策

- **决策 1（ArkUI @Builder 命名）**: 自定义 @Builder 方法名**严禁使用 ArkUI 内置组件名**（Table/Text/Button/Row/Column/Flex 等）——运行时静默跳过不报错，极难排查。Table 功能组命名 TblGroup。
- **决策 2（图标来源）**: 按钮图标一律用 Win 端官方图标（Desktop\icons png 版），保证与桌面版视觉一致（替代自行转换的 xpm，视觉更准）。
- **决策 3（id 唯一）**: 工具栏按钮 id 用独立命名空间（table_size/add_column/stats_columns/stats_rows），避免与菜单 id 混淆。
