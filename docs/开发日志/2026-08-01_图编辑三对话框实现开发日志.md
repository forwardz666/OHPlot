## 技术决策
- **数据加载触发**：MainLayout 采用 `if (showXxx)` 条件挂载（组件创建时 isVisible 已为 true，@Watch 不会触发），故对话框用 `aboutToAppear()` 判断 isVisible 加载数据，同时保留 `@Link @Watch('onVisibleChanged')` 与既有 Plot2DDialog 模式对齐（两种挂载方式下均可用）。
- **列索引**：add_curve 的 cols 使用 getColumnInfo 返回的 `col` 字段（后端权威索引），非数组位置；ErrorBars 的 errColumnName 使用 getColumnInfo 的 `name` 字段。
- **error_bars compute 模式**：type=0 时带 percent（无效输入回退 5.0），type=1 仅带 type；column 模式只带 errTableId/errColumnName/direction；direction 默认 'y'（directionIdx 1）。
- **新 UI 文案**：复用现有资源键（graph_add_*、plot_*、dlg_curve、dlg_points、dlg_export_table、msg_select_column、common_*）；无既有键的新标签（Mode/Type/From/To/Style 等）用字符串常量，未新增 string.json 键（保持 i18n 改动最小，功能优先）。
