## 三、关键技术发现

1. **build_project 工具目录污染**（⚠️ 重要教训）：16:05 build_project 将产物输出到 `Desktop\app-discord\`（204KB 空壳），导致真机一直运行旧 HAP、SymbolDialog 出现"断裂假象"。**后续构建一律用命令行 hvigorw 在 ohos 目录执行**。
2. **真机验证暴露 3 个 ArkTS 编译错误**（此前 build_project 假成功掩盖）：MatrixPage ForEach 语法 / TableStatisticsDialog @Watch 位置 / MainLayout 连带。修复 commit e94d31b。
3. **string.json 并行编辑会损坏**（历史教训重演）：A agent 编辑后 en_US/zh_CN JSON 括号损坏（`]]`）。**必须串行编辑 + 编辑后 python 校验**。
4. **ArkTS 无 Picker 组件**：B2 用 Picker 导致 15 个编译错误，替换为 ForEach/Slider + placeholder 入构造器 + switch→if 链。
