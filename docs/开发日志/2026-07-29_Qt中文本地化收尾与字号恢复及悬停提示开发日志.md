## 二、逐问题：现象 → 取证 → 根因 → 修复 → 验证

### P-2 Qt 面板仍是英文（中文本地化只汉化了 ArkTS 层）
- **现象**：系统语言为 zh-Hans，ArkTS 菜单/工具栏已中文，但 Qt 渲染的表格、
  属性对话框仍为英文——半汉化。
- **取证**：hilog 显示 `system language=zh-Hans -> LANG=zh_CN.UTF-8`、
  `locale name=zh_CN`，但 `QTranslator … loaded=0`——.qm 未加载成功。
- **根因**：`QTranslator::load()` 用的是编译进二进制的 `TS_PATH`（CMake 相对路径
  `share/scidavis/translations`），该路径在 OHOS HAP 沙箱内不存在；CMake 路径变量
  不随沙箱重定位。
- **修复**：main.cpp 改为绝对沙箱路径为首选候选，编译期路径兜底：
  首选 `/data/storage/el2/base/haps/entry/files/translations/scidavis_<tag>.qm`；
  .qm 由构建期 POST_BUILD 拷入 rawfile，首启由 Ability 释放到沙箱 files。
- **验证**：真机 hilog `loaded=1`，截图 Qt 表格全中文（描述/类型/公式/应用(V)/
  数字/十进制/小数位数/所选列类型:双精度）。

### A 窗口文字变小（改中文后回归）
- **现象**：Qt 变中文后，所有窗口内文字明显变小。
- **取证**：grep main.cpp 找到 `app.setStyleSheet(...)`，其中
  `"QWidget{font-size:12px;color:#333333}"`；改中文前根本无样式表。
- **根因**：全局选择器 `QWidget{font-size:12px}` 把所有控件字号强制压到 12px。
- **修复**：移除 `font-size:12px`，改为 `"QWidget{color:#333333}"`，保留其余面板样式。
- **验证**：重编 .so → assembleHap → 安装 → 截图确认字号恢复默认大小。

### B 缺少 Windows 式悬停功能名提示
- **需求**：鼠标悬停按钮时显示功能名称，即使功能未适配也要显示。
- **选型**：理想的 `bindTips` 需 API 19+，但项目 `compatibleSdkVersion` 为 API 17
  （设备运行时 API 26），编译期 API 门禁会失败；改用 API 8+ 的
  `onHover`+`bindPopup`，无需改 build config。
- **实现**：接口加 `tip: string`（资源名）；struct 加 `@State hoverTipId` 与
  `tipText()`（`resourceManager.getStringByNameSync`，因 `bindPopup.message` 是
  `string` 非 `ResourceStr`）；ToolButton/DropButton 加 onHover+bindPopup（顶部
  `Placement.Bottom`、底部 `Placement.Top`）；三语 string.json 各补 38 个 `tip_*`。
- **验证**：assembleHap 通过（ArkTS 无报错），真机启动正常；hover 气泡属交互效果，
  需真机鼠标悬停观察（静态截图无法呈现）。

## 三、技术经验与最佳实践

1. **双链路本地化**：ArkTS `$r()` 与 Qt `QTranslator/.qm` 是两条独立链路，任一未通
   即半汉化；OHOS 上 .qm 必须用**绝对沙箱路径**加载，编译期相对路径必失效。
2. **全局 QSS 字体是陷阱**：`QWidget{font-size}` 会压制所有控件；调字号只针对具体
   控件类，视觉样式与字号规则要分离。
3. **API 选型受 compatibleSdkVersion 约束**：设备运行时 API 高不代表能编译——
   编译期门禁看 `compatibleSdkVersion`，选 API 时以其为准（本次 bindTips→bindPopup）。
4. **bindPopup.message 是 string**：本地化需 `getStringByNameSync` 同步解析，
   不能直接传 `$r()`。
5. **ninja POST_BUILD 的 Windows 无害失败**：Unix `mkdir -p`/`cp` 使 ninja exit 1，
   但 .so 已在链接步骤完成，判据是 `Linking CXX shared library` 已打印。
