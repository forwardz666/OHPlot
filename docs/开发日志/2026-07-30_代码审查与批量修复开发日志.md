## 三、逐问题诊断记录

### G: DataTable 缺第一行和标题行

**诊断**：C++ 侧 tableDataJson() 正确地从 row=0 开始构建数据数组。问题在 ArkTS 侧 Stack 布局——默认 alignContent 为 Alignment.Center，标题行 Row 被居中定位在 Stack 中间，叠加在数据行上。

**修复**：DataTable.ets 的 Stack 改为 Stack({ alignContent: Alignment.TopStart })，Scroll 加 .padding({ top: 28 }) 确保首行数据在标题行下方可见。

### T0: setChromeInsets 工具栏遮挡

**诊断**：命令已在 C++ 端注册（main.cpp:1539-1546），调用 g_mainWindow->setContentsMargins(0, top, 0, bottom)。但存在三个 bug：
1. 双层 setContentsMargins（g_mainWindow + centralWidget）产生双倍 inset
2. layout()->activate() 在 QMainWindow 上返回 nullptr 空操作
3. windowHandle()->setGeometry() 从当前几何计算 delta 导致累积偏移

**修复**：去掉 g_mainWindow 层的 setContentsMargins；去掉 layout()->activate() 和 windowHandle 块；改用 centralWidget()->updateGeometry()。

### B: KeyTextFixer 字母键和符号键

**诊断**：类名实际为 InputProbe（main.cpp:146-245），不在名为 KeyTextFixer 的文件中。printableTextFor() 函数（main.cpp:118-140）已正确处理字母键大小写和 Shift+数字键符号，但缺少 Shift+非数字非字母符号键的处理。

**修复**：在 printableTextFor() 的 Shift 分支中增加 11 个符号键映射表（减号→下划线、等号→加号、左中括号→左花括号、右中括号→右花括号、反斜杠→竖线、分号→冒号、单引号→双引号、逗号→小于号、句号→大于号、斜杠→问号、反引号→波浪号）。

### C: scidavis_call 分发器扩展

**诊断**：命令Registry 中有 4 个 stub（new_function、add_curve、add_error_bars、add_function）返回"requires UI dialog - not yet adapted"错误。其余 6 个（rescale、graph_pointer、zoom_in、zoom_out、screen_reader、data_reader）已有真实实现。

**修复**：替换 4 个 stub 为真实实现，使用正确的 ApplicationWindow 方法名（showCurvesDialog、addErrorBars、addFunctionCurve），new_function 使用默认参数调用 newFunctionPlot。

### D: 偏好设置持久化

**诊断**：getPreference 和 setPreference 命令已在 C++ 端 commandRegistry 中注册（main.cpp:1536-1555）。getPreference 在 queryCommands 中（同步读取），setPreference 为 fire-and-forget。PreferencesDialog.ets 的 aboutToAppear() 已加载所有 4 个设置，Apply 按钮已调用 setPreference。

**修复**：getPreference 的 JSON 响应使用字符串拼接，当值包含引号或反斜杠时产生无效 JSON。改为 QJsonDocument 序列化。

### E: 实时数据刷新

**诊断**：QtEventHost.ets 已处理 tableDataChanged/tableListChanged/plotListChanged 事件。TablePage 和 PlotPage 已有 @StorageProp Watch 监听。但 tableDataChanged 使用 tableId 字符串作为 AppStorage 值，同一表格两次编辑时值不变，Watch 不触发。

**修复**：QtEventHost.ets 中 tableDataChanged 事件改为 tid + '|' + Date.now().toString() 确保每次唯一。

### T3: 多层图支持

**诊断**：PlotPage.ets 已有完整的图形层选择器 UI、onGraphSwitch 处理器、graphCurveDataList 存储逐层曲线数据。但 onPlotSelected() 中将所有图层的曲线合并到 curveDataList，导致单图视图显示所有图层曲线叠加。

**修复**：onPlotSelected() 中 curveDataList 初始化为只取 graph 0 的曲线，而非合并所有图层。

### T4: 列宽自适应中文

**诊断**：DataTable.ets 的 computeColWidths() 使用固定 charWidth=8，未考虑中文字符宽度（约 2x ASCII）。

**修复**：添加 charDisplayWidth() 检测 CJK 字符范围（U+4E00-U+9FFF、U+3400-U+4DBF、U+FF00-U+FFEF、U+3000-U+303F）返回 2，ASCII 返回 1。添加 strDisplayWidth() 求和。computeColWidths 改用 strDisplayWidth 计算。

### T6: 结果日志自动滚动

**诊断**：MainLayout.ets 的 Results Log 面板使用 setTimeout(50ms) 调用 scrollEdge(Edge.Bottom)，但 Text 内容可能尚未完成布局；userScrolledUp 检测使用硬编码值 100000（内容高度）和 400（视口高度），不准确。

**修复**：去掉 setTimeout 和魔数。Text 的 onAreaChange 回调驱动 scrollEdge；Scroll 的 onAreaChange 捕获真实视口高度；onScroll 使用真实 scrollContentHeight 和 scrollViewportHeight 计算距离底部距离。

### F: Qt 侧事件推送

**诊断**：审计 5 个变更点：newTable（已发射 tableListChanged）、plot2D（已发射 plotListChanged）、importASCII（已发射 tableListChanged）、addTableColumns（已发射 tableDataChanged+tableListChanged）、tableStatistics（缺失）。

**修复**：tableStatistics handler 中在 s->showNormal() 后添加 scidavisEmitEvent(QStringLiteral("tableListChanged"))。
