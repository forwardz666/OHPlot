## 技术决策

- **决策 1（路线）**: 继续 OpenHarmony SDK 路径，不切 NEXT。核心依据：scidavis 是 Widgets 应用，
  NEXT 工具链验证的是 QML（AirStars）；NEXT Qt5Core 无 JS 桥（实测）；"换启动方式"非痛点。
  详见方案文档 §7。
- **决策 2（P1a）**: 读方向必须同步 `getDataSync()`——一次性 PasteButton 授权跨越异步回调无保证，
  违反规范 §2.2/§1.3；同步读取保证授权窗口内完成。
- **决策 3（P1b）**: KeyRelease 补全镜像 KeyPress——蓝牙键盘 release 事件同样 text 为空，
  编辑器消费 release 事件时也需要合成字符；合成事件 spontaneous=false 无递归风暴。
