# SciDAVis 菜单行为说明

## 现状分析
SciDAVis 是基于 Qt 5.15.12 的桌面应用程序，其菜单系统使用 Qt Widgets 实现，而不是 Web 技术。因此，无法使用 React JSX 语法或 Web 事件处理器（如 onMouseEnter、onClick）来控制菜单行为。

## Qt 菜单交互机制
Qt 的 QMenuBar 和 QMenu 组件具有内置的交互逻辑：
- 点击菜单项会展开/收起下拉菜单
- 悬停通常也会触发菜单展开（取决于系统设置）
- Qt 的菜单行为遵循平台惯例

## 可能的调整方法
由于我们没有 SciDAVis 的源代码，只能通过以下方式间接影响菜单行为：

1. **Qt 样式表 (QSS)**：可通过设置 QT_STYLE_OVERRIDE 环境变量或提供样式文件
2. **Qt 属性设置**：某些菜单行为可通过 Qt 属性控制
3. **平台插件参数**：QPA 插件可能支持某些菜单行为参数

## 当前实现
目前，菜单行为完全由 Qt 框架和 SciDAVis 应用程序自身控制，我们没有对菜单交互逻辑进行自定义。

## 建议
如需修改菜单交互逻辑，需要：
1. 获取 SciDAVis 源代码
2. 修改菜单相关的代码部分
3. 重新编译 Qt 应用程序部分
